# Application Screenshots Directory

This directory is reserved for application UI screenshots referenced in the root `README.md`.

## Required Screenshots Inventory:
1. `dashboard.png` — Executive Analytics Dashboard view (`http://localhost:8000`)
2. `patient-registry.png` — Patient Registry table with an active Patient Detail modal open
3. `molecular-analysis.png` — Molecular Analysis & Transcriptomics distribution view
4. `classification.png` — Patient Classification & 2D PCA scatter plot view
5. `treatment-prediction.png` — Supervised Treatment-Response Prediction & confusion matrix view
6. `personalized-strategy.png` — 7-Stage Personalized Treatment Strategy view

## Instructions for Capturing:
1. Launch the application locally:
   ```cmd
   run_single_port.cmd
   ```
2. Navigate your browser to `http://localhost:8000`.
3. Use the browser at standard 1920x1080 resolution (or windowed 1440x900) with clean light theme.
4. Capture each respective screen and save as PNG matching the exact file names above.
5. Commit and push to GitHub.
